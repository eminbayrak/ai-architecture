Install one skill, or several

Each folder is self-contained. Copy only what you want into .poolside/skills/.

fde-kb

Pull search over notes as they are. Index once. Query pastes chunks. No LLM in the indexer.

python scripts/link-skills.py --skills fde-kb

graph-memory

Push recall over typed triples. Build from extraction JSON. Query walks hops. No LLM in the walker.

python scripts/link-skills.py --skills graph-memory

llm-wiki

Compiled markdown wiki. Agent ingest. CLI query and lint. Optional compile-extracts, no model.

python scripts/link-skills.py --skills llm-wiki

List all: python scripts/link-skills.py --list. Combine: --skills fde-kb,graph-memory.

Under the hood

fde-kb

Once: index chunks the vault into SQLite (FTS always, vectors optional). Each question: search returns chunks. No LLM.

graph-memory

Once: extract JSON, then build writes graph.db. Each question: recall seeds names and walks hops. No LLM.

llm-wiki

Each new source: the agent writes wiki pages (this is the token cost). Each question: query returns top pages. lint is structural. compile-extracts can skip the LLM write if you already have graph JSON.

How we use them

graph-memory first for who / whose seat / who covers. If it is empty, fde-kb. llm-wiki if you want browsable pages and accept ingest cost. Write full names on pages. Slugs hide answers.
